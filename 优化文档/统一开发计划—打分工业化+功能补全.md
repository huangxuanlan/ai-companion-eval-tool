## 技术选型（基于 GitHub 调研）

| 能力 | 方案 | 理由 |
|------|------|------|
| 暂停/恢复 | `asyncio.Event` | 标准模式，每轮开始前 `await pause_event.wait()` |
| 取消 | `asyncio.Task.cancel()` + `CancelledError` | Python 原生，搭配 `try/finally` 做清理 |
| 并发控制 | `asyncio.Semaphore(N)` | 已有 `_queue_lock`，Semaphore 更适合打分场景 |
| 重试 | 显式 while 循环 + 指数退避 | 不用装饰器，避免吞 CancelledError |
| 进度推送 | 现有 WebSocket | 已有 `_push_ws_message()`，扩展事件类型即可 |
| 通知 | `Notification API` + `document.title` 闪烁 | 无需 Service Worker，直接用 |
| DB 优化 | WAL + PRAGMA 优化，暂不分表 | 3MB 数据库远未到瓶颈，先优化再分 |
| AI 摘要缓存 | `conversations` 表新增 `ai_summary_cache` 列 | 最简方案 |

## Sprint 1：任务控制核心（P0，3天）

### S1.1 暂停/恢复/取消信号

**文件**: `server/services/task_control.py` [NEW]

```python
"""轻量任务控制信号，不依赖外部队列。"""
import asyncio

class TaskControl:
    """每个 conv_id 一个实例，管理暂停/取消信号。"""
    def __init__(self):
        self._pause_event = asyncio.Event()
        self._pause_event.set()  # 默认运行
        self._cancelled = False
        self.status = "running"  # running/paused/cancelled/completed
    
    async def checkpoint(self):
        """每轮开始前调用，检查暂停和取消。"""
        if self._cancelled:
            raise asyncio.CancelledError("用户取消")
        await self._pause_event.wait()
    
    def pause(self):
        self._pause_event.clear()
        self.status = "paused"
    
    def resume(self):
        self._pause_event.set()
        self.status = "running"
    
    def cancel(self):
        self._cancelled = True
        self._pause_event.set()  # 解除暂停阻塞以便退出
        self.status = "cancelled"

# 全局注册表
_controls: dict[str, TaskControl] = {}

def get_or_create(conv_id: str) -> TaskControl:
    if conv_id not in _controls:
        _controls[conv_id] = TaskControl()
    return _controls[conv_id]

def remove(conv_id: str):
    _controls.pop(conv_id, None)
```

### S2.2 并发打分

**文件**: `server/services/scoring_service.py` [MODIFY] `score_conversation()` L875

```python
async def score_conversation(self, conv_id, results, config, on_progress=None, max_workers=None):
    sem = asyncio.Semaphore(max_workers or self._max_workers)
    ctrl = task_control.get_or_create(f"score_{conv_id}")
    
    async def _do_one(index, result):
        await ctrl.checkpoint()
        async with sem:
            return await self._score_one_with_retry(result, config, ...)
    
    tasks = [_do_one(i, r) for i, r in enumerate(results)]
    scored = await asyncio.gather(*tasks, return_exceptions=True)
    # 过滤异常，保留成功结果
    return [s for s in scored if isinstance(s, dict)]
```

### S2.3 失败自动重试（引擎层 3 次）

在 `_score_one_with_retry()` 内嵌重试循环：

```python
async def _score_one_with_retry(self, result, config, max_retries=3):
    for attempt in range(1, max_retries + 1):
        score = await self.score_turn(turn_data, ...)
        if score.get("success"):
            return score
        if attempt < max_retries:
            delay = self._default_retry_delays[min(attempt-1, len(self._default_retry_delays)-1)]
            await asyncio.sleep(delay)
    return score  # 最终失败结果
```
