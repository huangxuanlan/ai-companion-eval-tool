## 已定位但不是当前未修缺陷

这些问题我核查过，但不属于“现在代码里还没修的持续性 bug”：

| 项目 | 结论 |
|---|---|
| 上传 Excel 按钮无法点击 | 最新服务上可点击，前端结构本身正常，更像旧页缓存或前后端版本不一致。 |
| 保存参数模板 `Failed to fetch` | 最新服务重启后 `POST /api/configs` 可成功返回 `200`，不是沙盒模式。 |
| 沙盒 / demo 模式导致写不进去 | 不成立。当前 `PUBLIC_DEMO_MODE=False`，数据库也在正常 `server/longform.db`。 |
| 批量只跑出 3 个 | 这通常是批量页默认并发值是 `3`，不是“最多只能跑 3 个模型”。[index.html](/E:/提效工具/长文模式生成/server/static/index.html:749) |
| 自动评分没出结果 | 批量页“自动评分”默认关闭，当前 UI 文案就是这么设计的；这更偏产品默认值，不是新冒出的程序错误。 |
