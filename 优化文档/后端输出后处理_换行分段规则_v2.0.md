# 后端输出后处理——换行分段规则

📋 版本：v2.0 | 日期：2026-05-11 | 关联文档：长短文模式融合_需求文档_v5.4

> **v2.0 变更**：旁白块不再按句号拆分，整块输出；旁白结构化字段从 `lines[]` 改为 `text`；规则精简至 9 条。

---

## 一、产品需求规则（共 9 条）

> 适用范围：仅 longform 模式执行此后处理管线，短文模式不受影响。

1. **解析**：用最外层括号匹配，将模型原始输出拆分为**旁白块**（括号内文本）和**对白块**（括号外文本）两种类型。
2. **旁白块不拆分**：每个括号对内的文本作为一个整体段落输出，不按句号换行。
3. **对白块整段加粗**：对白文本 trim 后用 `**...**` 包裹，不拆分。
4. **段落间双换行**：旁白块与对白块之间、对白块与对白块之间，统一用 `\n\n` 分隔。
5. **嵌套括号保留**：只匹配最外层括号，内层括号作为旁白文本原样保留。
6. **空/无效括号丢弃**：空括号 `（）`、括号内仅空格或标点的内容直接丢弃。
7. **未闭合括号兜底**：左括号无匹配右括号时，从左括号后到文本末尾全部视为旁白。
8. **合规前置门控**：字数 <300 或 >500、括号对数 <3，触发重写，不进入后处理。
9. **输出格式**：采用结构化 JSON（`blocks` 数组），旁白块为 `{"type":"narration","text":"整段文本"}`，对白块为 `{"type":"dialogue","text":"对白文本"}`。

---

## 二、核心概念定义

| 概念 | 定义 |
|:-----|:-----|
| 旁白 | 被`（）`或`()`包裹的文本内容 |
| 对白 | 括号外的文本内容（去除空白后非空） |
| 段落 | 一个完整的旁白块或对白块 |

---

## 三、处理流程

```
模型原始输出 → ①合规检测 → ②解析分段 → ③格式化 → ④组装输出
```

### 步骤①：合规检测

三条件任一命中即触发醒一醒重写，不进入后续步骤：

| 条件 | 阈值 |
|:-----|:-----|
| 字数不足 | < 300 字 |
| 字数超标 | > 500 字 |
| 圆括号对数不足 | < 3 对（含中文全角`（）`和英文半角`()`，按匹配对计数） |

### 步骤②：解析——将原始文本拆分为有序 token 列表

**核心逻辑：单次顺序扫描，用最外层括号匹配。**

```python
def parse(raw_text: str) -> list[dict]:
    """
    返回有序列表，每个元素为:
    {"type": "narration", "text": "..."} 或
    {"type": "dialogue", "text": "..."}
    """
    tokens = []
    i = 0
    buffer = ""  # 当前累积的对白文本

    while i < len(raw_text):
        ch = raw_text[i]

        # 遇到左括号（中文全角或英文半角）
        if ch in ('（', '('):
            # 先把之前累积的对白 flush
            if buffer.strip():
                tokens.append({"type": "dialogue", "text": buffer.strip()})
            buffer = ""

            # 找对应的右括号（只匹配最外层）
            depth = 1
            j = i + 1
            narration_text = ""
            while j < len(raw_text) and depth > 0:
                if raw_text[j] in ('（', '('):
                    depth += 1
                    narration_text += raw_text[j]
                elif raw_text[j] in ('）', ')'):
                    depth -= 1
                    if depth > 0:  # 内层右括号保留为文本
                        narration_text += raw_text[j]
                else:
                    narration_text += raw_text[j]
                j += 1

            # 未闭合情况：当作旁白处理到文本末尾
            if depth > 0:
                narration_text = raw_text[i+1:]
                j = len(raw_text)

            # 清理：去首尾空格，跳过空内容
            cleaned = narration_text.strip()
            if cleaned and cleaned not in ('。', ' ', '，'):
                tokens.append({"type": "narration", "text": cleaned})

            i = j
        else:
            buffer += ch
            i += 1

    # flush 最后的对白
    if buffer.strip():
        tokens.append({"type": "dialogue", "text": buffer.strip()})

    return tokens
```

**边界处理规则：**

| 情况 | 处理方式 |
|:-----|:---------|
| 嵌套括号 `（他看着你（眼神温柔）走过来）` | 匹配最外层，内层括号保留为旁白文本的一部分 |
| 未闭合括号 `（他转过身` | 从左括号后到文本末尾全部视为旁白 |
| 空括号 `（）` | 丢弃，不产生 token |
| 括号内只有空格/标点 `（。）` `（ ）` | 丢弃 |
| 中英文括号混用 | 统一处理，无差别对待 |

### 步骤③：格式化——对每个 token 做处理

#### 旁白：整块保留，不拆分

```python
def format_narration(text: str) -> str:
    """旁白整块输出，不按句号拆分"""
    return text.strip()
```

#### 对白：整段加粗，不拆分

```python
def format_dialogue(text: str) -> str:
    """对白整段加粗"""
    text = text.strip()
    if not text:
        return ""
    return f"**{text}**"
```

### 步骤④：组装输出——段落间统一双换行

```python
def assemble(tokens: list[dict]) -> str:
    """将 token 列表组装为最终输出字符串"""
    blocks = []

    for token in tokens:
        if token["type"] == "narration":
            formatted = format_narration(token["text"])
            if formatted:
                blocks.append(formatted)
        else:
            formatted = format_dialogue(token["text"])
            if formatted:
                blocks.append(formatted)

    return "\n\n".join(blocks)
```

## 五、边界 case 速查表

| # | 场景 | 输入 | 输出 |
|:--|:-----|:-----|:-----|
| 1 | 嵌套括号 | `（他看着你（眼神温柔）走过来）` | `他看着你（眼神温柔）走过来` （内层括号保留为文本） |
| 2 | 未闭合括号 | `（他转过身` | `他转过身` （当旁白到末尾） |
| 3 | 空括号 | `（）` | 丢弃 |
| 4 | 括号内纯标点 | `（。）` 或 `（ ）` | 丢弃 |
| 5 | 对白含引号 | `你看过"星际穿越"吗` | `**你看过"星际穿越"吗**` （引号保留，不额外处理） |
| 6 | 连续两段对白 | `行吧（…旁白…）走吧` | 两个独立对白块，中间夹旁白，各自加粗 |
| 7 | 旁白无句号 | `（他笑了笑）` | `他笑了笑` （不补句号，整段输出） |
| 8 | 旁白末尾有逗号无句号 | `（他笑了笑，转过身）` | `他笑了笑，转过身` （整段一行） |
| 9 | 对白首尾有空格 | ` 行吧 ` | `**行吧**` （trim后加粗） |
| 10 | 模型原始输出已有换行 | 括号间有`\n\n` | 解析后自然消化，不产生空 token |
| 11 | 旁白首尾有空格 | `（ 他笑了 ）` | `他笑了` （trim空格） |
| 12 | 旁白首尾有换行 | `（\n他笑了\n）` | 保留换行 |

## 六、数据结构

    {"type": "narration", "text": "整段旁白文本，不拆分"},

## 七、完整处理函数（可直接使用）

```python
def post_process_longform(raw_text: str) -> dict:
    """
    长文模式后端输出后处理主函数
    输入：模型原始输出（旁白用括号包裹，对白为纯文本）
    输出：结构化 blocks 列表
    """
    # Step 1: 合规检测（由上游完成，此处假设已通过）

    # Step 2: 解析
    tokens = parse(raw_text)

    # Step 3 + 4: 格式化 + 组装
    blocks = []
    for token in tokens:
        if token["type"] == "narration":
            text = token["text"].strip()
            if text:
                blocks.append({"type": "narration", "text": text})
        else:
            text = token["text"].strip()
            if text:
                blocks.append({"type": "dialogue", "text": text})

    return {"blocks": blocks}


def to_markdown(result: dict) -> str:
    """将 blocks 转为 Markdown 字符串（备选输出格式）"""
    parts = []
    for block in result["blocks"]:
        if block["type"] == "narration":
            parts.append(block["text"])
        else:
            parts.append(f"**{block['text']}**")
    return "\n\n".join(parts)
```

## 八、v1.0 → v2.0 变更记录

| 项目 | v1.0 | v2.0 | 变更原因 |
|:-----|:-----|:-----|:---------|
| 旁白拆分 | 按句号拆分为多行，句间 `\n` | 不拆分，整块输出 | 旁白作为场景描写是一个语义整体，拆分破坏阅读节奏 |
| 旁白结构化字段 | `"lines": [...]`（数组） | `"text": "..."`（字符串） | 不拆分后无需数组 |
| 段落间分隔 | 旁白内句间 `\n` + 块间 `\n\n` | 仅块间 `\n\n` | 简化为单一规则 |
| 换行规则总结 | 区分句间单换行和段间双换行 | 所有段落间统一双换行 | 降低实现和理解复杂度 |
| 文档结构 | 10 章 377 行 | 8 章，规则精简至 9 条 | 聚焦可执行规则，减少冗余 |
